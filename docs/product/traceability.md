## Shared contract fixtures

`cargo test --locked -p covalent-protocol --test contract_fixtures`, `swift test --package-path apps/apple`, and Android `:app:testDebugUnitTest` validate the committed version 1 configuration, manifest, pairing invitation, backup summary, transfer progress, node event, and API error contracts.

## Current evidence policy

The repository baseline inspected on 2026-08-27 is `dafca8efebaf904ed886d48ba8371b0fde53af56` (`v0.1.0`). The ignored artifacts currently present under `artifacts/` were captured on 2026-08-16 against older source states, so they are historical context and not exact-current UI evidence. Every new result must bind its artifact directory to the full source SHA, environment, and capture date; see [`ui-tour.md`](ui-tour.md).

The release tag and source documentation do not by themselves prove fresh visual, physical-host, or package acceptance. A release claim still requires the exact in-scope workflows, a fresh headed macOS UI/accessibility result, the verified ad-hoc package, and the documented physical Unraid drill. Apple Developer ID/notarization is excluded, and Android production signing is deferred. Do not treat an absent artifact, partial result bundle, or stale `working.md` entry as a pass.
