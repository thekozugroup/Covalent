## Remaining appliance acceptance

This release does not certify the GPhoto OS image. Solstice/Pi still need safe
Pictures journal recovery, full-folder completion, nearby discovery, cellular
handoff and fresh-image cold-boot checks. No drive was flashed, app data reset
or source photo deleted during publication. Covalent completion alone never
authorizes photo deletion; cleanup requires Google Photos-confirmed backup.
