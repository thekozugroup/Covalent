Covalent v0.1.0 — the first public alpha.

Covalent is a self-hosted backup and restore system for devices you already own.
It pairs devices directly over a LAN or Tailnet, stores encrypted verified chunks
only on devices you explicitly choose, and restores relative paths only beneath a
destination you authorize. There is no cloud service, no hosted account, and no
telemetry.

## What works in this release

- Signed device pairing and revocation over authenticated QUIC (transport v2).
- Streaming encrypted backup with content-addressed, verified chunks.
- Exact explicit replica placement — Covalent never picks storage for you.
- Corruption detection and repair.
- Signed restore preview, plus resumable restore confined to an authorized root.
- Crash recovery across the node, storage, and transfer layers.
- TLS-only management console and local API (persisted contract: protocol v1).
- Read-only source mappings, so a container can never write to a backup input.

## What is alpha

This is a `0.x` release and the on-disk and wire formats may change. Treat it as
something to evaluate, not as your only copy of anything that matters.

- Back up the `/data` appdata path separately. It holds identity and key state,
  and losing it means losing access to the encrypted chunks.
- The macOS build in this release is **not** notarized (see below).
- Supported platforms are Unraid, macOS, and Android. **iOS and Windows are not
  supported and nothing in this release installs on either.** No iOS or Windows
  artifact is published. The repository contains an iOS target built from shared
  Apple sources, but it is unreleased and out of scope for now.
- Hosted accounts, automatic replica placement, and restores outside an
  authorized root are out of scope by design, not pending work.

## Install

### Unraid / Docker (Tier 1)

The container image is multi-architecture (`linux/amd64` and `linux/arm64`),
cosign-signed, and published with an SPDX attestation.

```sh
docker pull ghcr.io/thekozugroup/covalent:v0.1.0
```

Verify the signature before you run it — the digest and the exact command are in
`covalent-container-digest.txt` attached to this release:

```sh
cosign verify ghcr.io/thekozugroup/covalent:v0.1.0 \
  --certificate-identity-regexp '^https://github.com/thekozugroup/Covalent/' \
  --certificate-oidc-issuer https://token.actions.githubusercontent.com
```

On Unraid, add the template from
`packaging/unraid/covalent.xml`. Map each share you want backed up **separately
and read-only**, keep `/config` and `/data` on appdata, and set
`COVALENT_HTTPS_HOST` to the exact DNS name your clients will use. The console is
TLS-only; enroll the local CA from
`/config/caddy/data/caddy/pki/authorities/local/root.crt` before entering an API
token.

### macOS (Tier 1) — unsigned in this release

`Covalent-v0.1.0-macOS-arm64-unsigned.zip` is an Apple Silicon build. It is
**ad-hoc signed, not Developer ID signed and not notarized**, because this
project does not yet have an Apple Developer Program membership. Gatekeeper will
quarantine it, and that warning is accurate — you are trusting the checksum and
the build provenance below rather than Apple's review.

Verify it first:

```sh
shasum -a 256 -c Covalent-v0.1.0-macOS-arm64-unsigned.zip.sha256
```

Then either right-click the app and choose **Open** (and confirm once), or:

```sh
xattr -dr com.apple.quarantine /Applications/Covalent.app
```

Apple Silicon only. There is no Intel or universal build, and no auto-update.
A notarized build will replace this lane once a Developer ID certificate exists.

### Android (Tier 1)

Install `Covalent-v0.1.0-android-release.apk`. It is signed with the project's
release key using the v1, v2, v3, and v4 signature schemes. Verify it against
`Covalent-v0.1.0-android-SHA256SUMS.txt` before installing, and keep the APK
source consistent — a future update will only install over this one if it carries
the same signing certificate.

The `.aab` is published for completeness; it is not installable directly.

## Provenance

Every artifact on this page was produced by a tagged GitHub Actions run from this
exact commit, gated on the full Tier 1 software suite plus a verified release
commit signature. Attached alongside the binaries:

- `covalent-container.spdx.json` — container SBOM (Syft, SPDX).
- `covalent-container-digest.txt` — the immutable multi-arch digest and the
  cosign command that verifies it.
- `Covalent-v0.1.0-android-sbom.cdx.json` — Android SBOM (CycloneDX).
- `Covalent-v0.1.0-android-r8-mapping.txt` — R8 deobfuscation mapping.
- `Covalent-v0.1.0-macOS-dependency-inventory.tar.gz` — Apple dependency
  inventory, built with `SOURCE_DATE_EPOCH=0`.
- `*-SHA256SUMS.txt` / `*.sha256` — checksums for everything above.
