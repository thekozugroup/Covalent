## Canonical production scenario

Create three temporary nodes without external services; pair them with matching authentication strings; disable and re-enable LAN discovery; connect over an explicit LAN or Tailnet-style address; create one-way source-to-destination links using the restricted rclone worker; verify fan-out and isolated family contributions without reverse writes; exercise Manual, Scheduled, and Continuous cadence; verify both source-deletion choices, destination-deletion suppression, and explicit restoration; interrupt and recover a transfer without claiming unrelated destination files; reject traversal and symlink attacks; converge shared settings; revoke a peer; verify exact relative paths and content; and clean up owned processes and fixtures. The active authority is [Product requirements](../product/requirements.md#active-completion-goal).
