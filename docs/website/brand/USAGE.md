# Covalent brand assets

Use `covalent-mark.svg` on light backgrounds and `covalent-mark-light.svg` on
dark backgrounds. These retain the overlapping-circle geometry used in the
current console. Keep the 88:64 aspect ratio and leave at least one circle
stroke's width of clear space. Use an accessible label when the mark is a link;
use empty alt text when adjacent text already says Covalent.

The shaded overlap expresses a shared bond. Do not add arrows, cloud symbols,
or competing app marks. Use the name **Covalent** in normal title case.

`social-card.png` is the 1200 × 630 social preview. `social-card.svg` is its
editable source. It is a promotional graphic, not an application screenshot.

| Purpose | Tailwind color | Hex |
| --- | --- | --- |
| Primary action / mark | Slate 600 | `#475569` |
| Hover / emphasis | Slate 700 | `#334155` |
| Main text | Zinc 800 | `#27272a` |
| Secondary text | Zinc 600 | `#52525b` |
| Background | Zinc 50 | `#fafafa` |
| Sidebar | Zinc 100 | `#f4f4f5` |
| Divider | Zinc 200 | `#e4e4e7` |
| Dark-background mark | Slate 50 | `#f8fafc` |

Follow the product's serif headings (Georgia/serif), system sans-serif body,
quiet whitespace, thin rules, and compact pill actions. Retain the website's
existing navigation and layout. No new font download is required.

Assets are original Covalent artwork under the repository's MIT license.
Product screenshots include shadcn and Lucide components; their notices are in
`../ASSET-NOTICES.md`. The SVGs contain vector geometry and text only.
