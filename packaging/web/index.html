Enter the access token

Enter the access token for this server. It was created on the computer where the server was set up.

What it is. A long line of letters and numbers that proves you may manage this server. It is not the short setup code from the server log: a setup code cannot unlock this console.

Where to find it. During setup, covalent claim saved the token in a file named local-api-token, in a new folder that only you can open on that computer. Choose that file, or open it and paste its contents.

The token stays in this browser tab and is sent only to this server.

        Advanced archive tools
        Existing backup, restore, and recovery data remains available through the command line.         Container network choices
        Bridge mode exposes HTTPS management on TCP 8443 and device-to-device traffic on UDP 8787. Enroll the package CA or use a system-trusted same-host proxy before entering an access token. Host networking can improve multicast discovery; a Tailscale sidecar or host Tailnet address is optional.
