        Advanced server tools
        
        Advanced archive tools
        Existing backup, restore, and recovery data remains available through the command line. Run covalent backups, covalent backup --help, covalent restore-preview --help, covalent restore-execute --help, or covalent-node --help from a trusted terminal. Removing these screens does not delete files, keys, archives, or settings. Covalent does not migrate them automatically.
        
        
        Container network choices
        Bridge mode exposes HTTPS management on TCP 8443 and peer traffic on UDP 8787. Enroll the package CA or use a system-trusted same-host proxy before entering a token. Host networking can improve multicast discovery; a Tailscale sidecar or host Tailnet address is optional.
